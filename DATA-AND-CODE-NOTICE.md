# Data and code notice

## Source data

This project analyzes Cainiao-AI's LaDe-D last-mile delivery dataset. The LaDe-D card on Hugging Face currently labels the dataset `apache-2.0`. The LaDe project README describes the dataset as intended for research purposes. The original LaDe paper's datasheet describes the dataset as CC BY-NC 4.0 and requests citation. These source statements do not align, so this project does not claim to resolve which terms control.

No raw LaDe-D file is included here. Obtain the data from the official source and follow the terms presented there. This repository is a free educational portfolio project. Do not use the source data or its derived outputs commercially unless you have confirmed that the applicable terms allow it.
